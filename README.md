# An Tam Bus Frontend

Frontend demo cho website dat ve xe khach theo dac ta `YEU_CAU_UI_UX.md`.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS 4
- Lucide React icons

## Chay local

```bash
npm install
npm run dev
```

## Kiem tra truoc deploy

```bash
npm run typecheck
npm run lint
npm run build
```

## Deploy

Co the deploy len Vercel/Netlify hoac bat ky host Node.js nao ho tro Next.js:

```bash
npm run build
npm run start
```

Day la frontend demo dung mock data cuc bo. Cac luong auth, OTP, giu ghe, thanh toan, callback, huy/hoan tien va phan quyen da co UI/trang thai mau nhung can backend/API that de van hanh production.
